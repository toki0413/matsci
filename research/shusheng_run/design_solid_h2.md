# 固态储氢系统人工智能辅助设计系统 · 总体设计方案

## 0. 系统定义

一套覆盖"原子 → 材料 → 系统 → 场景"四个尺度、以世界模型为核心引擎、以强化学习为决策核心、以主动学习调度稀缺试验资源的**端到端自主设计系统**。输入是场景应用需求，输出是经过验证的储氢系统设计方案及其推演依据。

## 1. 总体架构（七个组成部分，一条主闭环）

```
                    ┌─────────────────────────────────────────┐
                    │              场景接口层                    │
                    │   场景应用需求 → 设计目标与约束形式化       │
                    └──────────────────┬──────────────────────┘
                                       ▼
┌──────────┐   ┌──────────┐   ┌──────────────┐   ┌──────────┐   ┌──────────┐
│ 材料引擎  │──▶│ 仿真内核  │──▶│  世界模型    │──▶│ 决策引擎  │──▶│ 设计输出  │
│ (LAM)    │   │(神经算子) │   │ (推演+UQ)   │   │  (RL)    │   │          │
└──────────┘   └──────────┘   └──────┬───────┘   └──────────┘   └──────────┘
       ▲              ▲              │                               │
       │              │              ▼                               │
┌──────────┐   ┌──────────┐   ┌──────────────┐                       │
│ 数据平台  │◀──│ 试验子系统 │◀──│ 主动学习调度器 │◀──────────────────────┘
└──────────┘   └──────────┘   └──────────────┘
```

**主闭环**：材料引擎 → 仿真内核 → 世界模型推演 → RL 决策 → 设计方案 → 主动学习调度器决定"下一个最有价值的试验" → 试验子系统执行 → 数据平台入库 → 全系统更新。场景需求从顶部进入，设计方案从右侧输出，运行数据从应用端回流。

## 2. 组件规格

**C1 材料引擎（原子尺度）**

- 底座：双预训练原子间势（MACE-MPA + CHGNet）交叉验证；输出永远带置信度标注。
- 功能：镁基合金元素筛选与改性设计（氢化焓/熵、平台压力、扩散势垒）、输出材料本构参数（热导率、渗透率、反应速率、力学性能）给仿真内核。
- 规则：LAM 只做候选推荐与参数生成；每批候选抽检 ≥10% 做 DFT 或实验校准。

**C2 仿真内核（材料-结构-场尺度）**

- 物理信息神经算子（PINO，FNO 骨干 + 守恒损失：质量/动量/能量），多保真训练：粗网格 FEA → 精细 FEA → 实验逐级对齐。
- 功能：输入几何/工况/本构参数，输出温度场、应力场、流场与性能指标；**全程可微**，性能梯度可回传至材料参数与几何参数。
- 物理模型（氢热耦合 FEA）作为残差基准与预训练数据发生器，不参与在线推理。

**C3 世界模型（推演引擎）**

- 以仿真内核为动力学基础构建 latent dynamics（RSSM 结构），在潜在空间 rollout 系统全生命周期演化。
- 功能：交互推演（"若采用 X 材料、Y 结构、Z 工况，则系统行为为…"）+ 不确定度量化（deep ensemble）。
- 可信机制：残差学习（预测 = 物理模型输出 + NN 修正）；UQ 超阈值时自动降级——缩小推演步长、退回仿真内核重算、或申请真实试验。

**C4 决策引擎（RL）**

- Dreamer 风格 model-based RL：actor-critic 全部在 C3 的梦境中训练；奖励为多目标 Pareto 前沿（储氢密度、放氢速率、成本、安全），最终方案由专家在 Pareto 解集中裁决。
- 状态 = 当前设计 + 推演性能 + 不确定度；动作 = 材料/结构/工况的序贯修改；梦境合成数据不进入验证集。

**C5 主动学习调度器**

- 输入：C3 的 UQ 结果 + C4 的候选设计集；用 Bayesian optimization（不确定度 × 预期改进双准则）排出下一批试验优先级。
- 输出：给 C6 的试验工单（试样规格、工况、测量量）。这是全系统唯一消耗昂贵实验资源的阀门。

**C6 试验子系统**

- 原型试验装置 + 标准作业流程；支持快速换样以配合主动学习节奏；试验数据实时入库。
- 职责：执行 C5 工单 + 对最终设计方案做关键性能验证。

**C7 数据平台**

- 存储：试验数据、FEA 数据、场数据（温度/应力/流场）、LAM 计算数据、运行工况数据；统一混合参数化表征与元数据规范。
- 服务：数据版本管理、训练集/验证集隔离（梦境数据只能进训练集）、向各组件的标准化数据接口。

## 3. 数据流与接口（定死四个）

| 接口 | 从 → 到 | 内容 |
| --- | --- | --- |
| I1 | C1 → C2 | 材料本构参数 + 置信度 |
| I2 | C2 → C3 | 可微场预测模型（权重级共享） |
| I3 | C3/C4 → C5 | 候选设计 + UQ + Pareto 评级 |
| I4 | C6/C7 → 全系统 | 新数据触发增量训练（LAM 微调、算子增量、世界模型更新） |

## 4. 一次完整设计任务的生命周期

1. **需求形式化**：场景需求 → 设计目标、约束、验收指标；
2. **材料筛选**：C1 零/少样本给出候选材料库（≤100 个），抽检校准后浓缩至 ≤10 个；
3. **梦境预演**：C4 驱动 C3 对候选"材料×结构×工况"空间做大规模梦境 rollout；
4. **决策收敛**：RL 策略收敛出 Pareto 候选集（≤5 个），专家裁决出 1–2 个方案；
5. **定向验证**：C5 按 UQ 排出验证工单，C6 执行关键试验；
6. **回流更新**：试验数据入库，触发全链路增量更新；若验证不通过，回到步骤 2，世界模型已比上一轮更准；
7. **交付**：设计方案 + 性能报告 + 完整推演轨迹（可解释依据）；
8. **运行孪生**：应用端运行数据持续回流，系统在线演化，支撑运维与下一代设计。
