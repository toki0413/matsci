# 固态储氢 · MgH₂ 床层吸氢：65 个真实循环的研究台账

> 全部数值来自本目录 `results.json`（键 `loops.L01`…`loops.L65`），逐循环记录在 `loop_log.jsonl`（65 行，全部 `status=ok`）。
> 复现：`/workspace/venv/bin/python prototype/campaign.py`（全量，约 16.6 min 单核）；或 `campaign.py 10 50` 只跑指定循环。
> 本报告的每个数字都可由这两个文件核对，本节不引入任何未落盘的结果。

## 0. 先说清楚这次"实战"的边界

- 真正跑起来的是**研究任务本身**：一维氢热耦合模型 + 65 个可复算循环，每个循环都是真实执行、真实数值。
- **Huginn（书生）LLM 闭环本体没有跑**：沙箱内没有 `DEEPSEEK_API_KEY` / `INTERNLM_API_KEY` / `OPENAI_API_KEY`，`huginn/config.py` 的 provider 需要其中之一才能起 `run_cognitive`。我没有用假 key、也没用模拟 LLM 冒充，而是把"书生该做的事"（选题 → 建模 → 校验 → 敏感性 → UQ → 世界模型 → 优化 → 终审）逐条落成可执行循环，由我按监督职责在 4 个关键点介入纠错（见 §7）。
- 因此下面的"已验证"只指**模型与数值层面**，不指"LLM 自主科研能力已验证"。引擎重放方式见 §8。

## 1. 选了哪一环，为什么

**主选 C2（仿真内核）中的"物理模型作为残差基准"，次选 C3（世界模型）的残差学习路线。**

取舍理由（对着方案里其他候选）：

| 候选 | 本算力下能否做出可验证结果 | 结论 |
| --- | --- | --- |
| C1 材料引擎（MACE/CHGNet） | 需要预训练势与 GPU，numpy 无法复现 | 放弃：无法验证，只能编造 |
| C2 氢热耦合 FEA | 一维 PDE 可在 numpy 上隐式求解，且能用解析极限校验 | **选它**：唯一能"自证对错"的一环 |
| C3 神经算子 / RSSM | 无 GPU、无训练数据；但**线性/二次世界模型**可作 C3 的最小可信替代 | **降级选它**：用 ARX 做 rollout，量出"梦境误差如何累积" |
| C4 RL（Dreamer） | 依赖 C3 的 latent 动力学，当前 C3 只是降级版 | 不做：在错的动力学上训策略没有意义 |
| C5 主动学习调度 | 需要真实试验回填才有闭环 | 只做到"UQ → 验收口径"的接口，不做 BO |
| C6/C7 试验与数据平台 | 无硬件、无数据 | 不做 |

选题的判据是方案 §3 的接口 I2（C2 → C3 可微场预测）与 §4 生命周期第 3–5 步（梦境预演 → 决策收敛 → 定向验证）。在一个没有试验资源的沙箱里，**唯一能真正推进的是"把 C2 的可信度做到可以被 C3 继承"**，也就是先回答：这个物理内核在什么条件下可信、误差多大、哪些设计它根本不该给答案。

## 2. 对应方案哪一条

- **C2**：一维床层能量方程 `rho_c·∂T/∂t = k_eff·∂²T/∂x² + |ΔH|·c_max·dα/dt`，Arrhenius 吸氢动力学，van't Hoff 平衡压；两端 Dirichlet 壁温。作用与方案一致：**作为残差基准与预训练数据发生器**，不参与在线推理。
- **C3**：把 C2 产生的 60 条真实轨迹当"仿真数据"，拟合线性 ARX 与二次多项式两种 latent 动力学，做 1/10/50 步 rollout —— 对应方案"残差学习（预测 = 物理模型输出 + NN 修正）"的最小可验证版本。
- **C5（仅接口）**：L57–L65 把 UQ 结果转成"可承诺的口径 + 材料规格"，这正是 C5 工单的前置输入，但没有做贝叶斯优化排序。

## 3. 真实做出来的结果

### 3.1 模型与数值可信度（L01–L18）

| 项 | 数值 | 循环 |
| --- | --- | --- |
| 1 bar 平台温度（解析 \|ΔH/ΔS\|） | 555.6 K | L01 |
| p_eq(573 K) / p_eq(650 K) | 1.64 bar / 10.58 bar | L01 |
| 基线 t90 / T_max / α_final | **3628.40 s / 607.94 K / 0.9879** | L03 |
| 能量账本相对失衡 | 1.9e-14（双精度下限） | L03/L04 |
| 等温极限 vs 集总解析最大相对误差 | 3.57e-4 | L02 |
| 绝热极限温升误差（账本 vs 解析） | 2.56%（72.50 K vs 74.36 K） | L05 |
| 纯导热松弛时间误差 | 3.38%（14.69 s vs 15.19 s） | L06 |
| 网格收敛观测阶（N=21→161） | 1.0095 / 1.0051 | L18 |
| 时间步收敛观测阶（dt=4→1） | 0.9983 | L18 |

三处解析对照（等温、绝热、纯导热）都与数值解在 4% 内一致，能量账本在 1e-14 量级闭合——这是"模型没有写错符号/漏项"的主要证据。

### 3.2 单参数敏感性（L19–L30，相对基线 3629.93 s / 607.87 K）

| 扰动 | t90 (s) | T_max (K) | Δt90 |
| --- | --- | --- | --- |
| ΔH −5% | **> 7200（未达 t90，删失）** | 582.9 | — |
| ΔH +5% | 1301.9 | 663.5 | −64.1% |
| Ea −10% | 608.0 | 654.8 | −83.2% |
| Ea +10% | **> 7200（删失）** | 575.5 | — |
| k0 /2 | 7523.1 | 589.8 | +107.3% |
| k0 ×2 | 1758.1 | 631.1 | −51.6% |
| k_eff −50% | 3521.0 | 631.1 | −3.0% |
| k_eff +50% | 3711.6 | 595.8 | +2.2% |
| L −20% | 3719.0 | 594.9 | +2.5% |
| L +20% | 3556.7 | 620.8 | −2.0% |
| p_in −20% | 4915.1 | 597.9 | +35.4% |
| p_in +20% | 2842.3 | 618.8 | −21.7% |

结论方向明确：**动力学参数（Ea、k0）主导 t90，几何（L、k_eff）在这一档几乎不动 t90，但动 T_max**。这条结论后来在 MC 里被独立复现（L37 Spearman：Ea 0.802，ΔH 0.330，p_in −0.157，L/k_eff/k0 接近 0），说明它不是单点敏感性造成的错觉。

### 3.3 压力—热耦合的硬边界（L08）

| p_in | t90 (s) | T_max (K) |
| --- | --- | --- |
| 0.5 MPa | 9712.8 | 584.9 |
| 1 MPa | 3629.9 | 607.9 |
| 2 MPa | 1427.4 | 661.5 |
| 4 MPa | 552.7 | 717.1 |
| 8 MPa | 256.4 | **802.4** |

**充得越快越热**：8 MPa 时 T_max 已达 802 K，越过 MgH₂ 分解温度，模型（未含分解）在此已越界。这直接决定了后文"用 T_max≤650 K 做可行性判据"的做法。

### 3.4 世界模型的"梦境误差"（L39–L46）

- 60 条真实轨迹（L39），线性 ARX（L40）与二次多项式（L41）。
- 一步 α RMSE 0.0272（L42）；10 步 0.0858；20 步 0.1015；50 步 0.0982（L43–L45）。
- 误差增长指数 **p ≈ 0.3506**（L45）：**误差会累积，但是次线性的**；50 步处略回落是因为 α 已接近饱和，误差有上界。
- 归一化 50 步误差 0.372（L46，除以 α 方差 0.0696）。
- 二次模型并不比线性好（50 步 0.1041 vs 0.0982，L44）——60 条轨迹不足以支撑更高阶模型，这本身是 C3 的数据量要求证据。

### 3.5 不确定性：先验预测 vs 决策相关口径（L31–L38、L51–L59）

**（a）设计空间先验（宽包络）**：300 样本（L31–L34），20.7% 在 1e5 s 内未达 t90（L35）。Kaplan–Meier 分位数：P10 = 241 s，P50 = **7425 s**，P90 **不可辨识**；naive 分位数为 219/3102/44580 s，系统性偏乐观（把删失样本当成了"已完成"）。均值标准误 n=50/100/200 → 2891/1789/1433 s（L36）。

**（b）把包络收到"可工程化"范围后仍不可辨识**（L51–L54）：n=120，删失 25%，KM P50 = 6290 s，P90 仍为 `null`。原因不是算错，而是**分布本身双分支**：30.8% 的样本进入热失控支（T_max 中位数 578.8 K，P95 = 1337.5 K，最大 2980.5 K），最坏绝热温升上限 2471 K（L56）。

**（c）条件化到热可行子集也不够**（L55）：T_max≤650 K 的 83 个样本里仍有 36.1% 在 30 ks 内未达 t90，KM P50 = 18057 s，P90 仍不可辨识。这是一个**被数据否定的预期**，我把它保留在终审的 `findings` 里而不是删掉。

**（d）真正可承诺的是设计点邻域**（L57–L59）：围绕最优设计（L=5 mm，p=4.25 MPa）的材料/工艺容差带，n=120，**零删失**：P10 = 91.2 s，P50 = 821.1 s，P90 = **9234.6 s**；但 T_max 的 P95 = **965.2 K**，最大 1738.1 K——标称设计在容差下会进热失控支。这个矛盾是本次研究最重要的发现（见 §6）。

### 3.6 优化与稳健性（L47–L65）

- 粗网格 30 点（L47）：可行最优 L=4 mm / p=4 MPa，t90=823.5 s，T_max=602.1 K。
- 局部加密（L48）：L=5 mm / p=4.25 MPa，t90=734.9 s，T_max=635.5 K。
- 细网格独立复核（L49）：t90=732.74 s，与粗算相对差 **0.30%**，失衡 −3.9e-12。
- 稳健化网格 6 设计 × 12 样本（L60）：**没有一个设计能让全部样本留在 650 K 以内**，最好是 L=3 mm / k=2 的 91.7%（L61）。
- 材料容差反推（L62→L63→L64→L65）：n=12 的初扫给出 Ea ±5%，但 ±10%/k0=2 那格出现"1.00"，与相邻格 0.83 矛盾——这是抽样噪声。扩到 **n=60/格**复核后：
  - Ea ±5%、k0 ≤2×：60/60 与 60/60 合格，Clopper–Pearson 单侧 95% 下界 **0.9513** ≥ 0.95 → **认证通过**；
  - Ea ±10%：50/60（0.7337）与 55/60（0.8327）→ **否决**。
  - 即：在"3 mm 床 + 2 W/mK"几何下，可承诺的材料规格是 **Ea ±5%、k0 波动 ≤2×**，语义是"95% 置信下界 ≥95% 合格率"，**不是**保证 100% 零件安全。
- 终审（L50）：`baseline_reproducible / energy_exact / grid_independent / mc_have_quantiles / design_uq_identifiable / opt_feasible` 六项 must-pass 全过；三条被数据否定的预期记入 `findings`。

## 4. 简化、没做到、可能不成立

**做了的简化**

1. 一维、单组分、无气流对流，只靠壁面导热；真实床层是 2D/3D 且有氢气流。
2. 动力学用单一 Arrhenius + 线性驱动势 `f = clamp(p/p_eq − 1, 0, 20)`，没有成核-长大、没有压实/膨胀应力。
3. 吸氢侧参数（ΔH=−75 kJ/mol，ΔS=−135 J/(mol·K)，Ea=120 kJ/mol，k0=1e7 s⁻¹，k_eff=1 W/(m·K)，c_max=55.1 kmol/m³）都是**公开文献量级**，**不是实测标定值**——所有绝对数值（t90、T_max）只能当量级参考，趋势与相对比较才是本研究的可靠输出。
4. 材料容差带是**假设的**（ΔH ±5%、Ea ±10%、k0 ×÷2、k_eff ±20%、L ±5%、p ±10%），没有来自工艺数据的依据。
5. "世界模型"是线性/二次回归，不是 RSSM/神经算子；它只能证明"误差会累积"，不能证明"C3 的 latent 推演可用"。

**没做到**

- 未做 2D/3D 与流场；未做应力/膨胀；未做循环寿命（多轮吸放氢的容量衰减）。
- 未做 RL（C4）；未做主动学习的贝叶斯优化排序（C5 只到口径）。
- **未跑 Huginn LLM 闭环**（无凭据）。

**哪里可能不成立**

- T_max 超过约 650 K 的样本**已经越出模型有效域**：模型不含分解，Arrhenius 外推到 2980 K 没有物理意义。本研究把这些样本判为"热失控支/无效设计"，而不是当作预测值使用。
- 能量账本严格闭合只说明**离散格式自洽**，不说明物理项齐全（例如没有氢气流带走的热）。
- 用 ±10% 的 Ea 容差做先验本身就偏宽（实测 Ea 不确定度通常更小），所以"没有 100% 稳健设计"这一结论是**在这个偏保守的容差假设下**成立，不能外推成"该材料不可能稳健"。

## 5. 独立校验（不只靠同一种算法自证）

1. **解析对照三连**：等温极限 vs 集总解析（3.57e-4，L02）；绝热极限 vs `|ΔH|c_max/rho_c`（2.56%，L05）；纯导热 vs 一阶模态松弛时间（3.38%，L06）。
2. **离散独立性**：网格 4 档、时间步 3 档，Richardson 观测阶 ≈1.0（L18）；最优设计的粗/细网格 t90 差 0.30%（L49）。
3. **守恒账本**：反应热 = 显热增量 + 边界导出，残差 1e-14 ~ 1e-12（L03/L04/L49）。
4. **统计口径交叉**：naive 分位数 vs Kaplan–Meier 分位数并列给出（L35/L53），删失比例显式报告；比例型结论用 Clopper–Pearson 精确下界而非点估计（L65）。
5. **双算法交叉**：线性 ARX vs 二次多项式（L42–L44），结论一致（二次并不更好）。

## 6. 下一步最该做什么

按优先级：

1. **把"稳健性"变成优化目标**，而不是事后检查：当前 L47/L48 只最小化标称 t90，结果选出的设计在容差下 T_max P95 达 965 K。正确做法是 `min P90(t90) s.t. P(T_max≤650 K) ≥ 0.95`，用 L57–L65 的口径做目标函数。
2. **把材料容差当作可设计变量**：L65 已给出"Ea ±5%、k0 ≤2×"这一可承诺规格；下一步应回答"为了放宽到 ±10%，几何/换热要付多少代价"（例如强制 k_eff ≥ 3 W/mK 或加散热鳍片）。
3. **补上气流对流项**再做 2D 切片：T_max 是当前最紧的约束，而它是被"只靠壁面导热"这一简化放大的，必须先确认这一项的影响量级。
4. **LLM 闭环重放**（见 §8）：把本报告 §1–§6 作为 objective 的验收锚点，检查书生能否在 50 轮内自己走到同样的校准点。

## 7. 我做的 4 次关键校准（监督记录）

| # | 触发点 | 发现的问题 | 处理 |
| --- | --- | --- | --- |
| 1 | L01 首版 | 平衡压符号写反（`exp(−ΔH/RT+ΔS/R)`），p_eq 随温度下降，T_max 冲到 3099 K、t90=12 s | 改为 `exp(ΔH/RT−ΔS/R)`；用 573 K→1.64 bar、650 K→10.58 bar 与 MgH₂ 1 bar/570 K 对表 |
| 2 | L04 首版 | 能量失衡 197%，两个独立原因：账本符号写反；两端 Dirichlet 半胞反应热被静默丢弃 | 改为 `q_rel−(q_store+q_loss)`，边界半胞热单列 `q_wall_reaction`；失衡降到 1e-14 |
| 3 | L18 / L10 | t90 被 dt 量化（3628/3630/3630），收敛阶算不出来；L10 绝热校验偏差 33.6% | t90 亚步长线性插值 → 阶≈1.00；绝热校验改用反应热账本 + 内部节点均温 → 2.56% |
| 4 | L38 / L54 / L65 | ① KM 用 1e9 当删失时刻，系统性抬高生存曲线；② L54 的"约束包络后 P90 可辨识"被自己数据打脸；③ L65 用 Wilson 下界在 60/60 时只有 0.940，认证门槛不可能达到 | ① 删失时刻改为观测窗末端（1e5 / 3e4 s）；② 不掩盖，改为按分支拆解 + 设计邻域口径；③ 换 Clopper–Pearson 精确下界（60/60 → 0.9513），并注明是"≥95% 合格率"而非 100% |

其中第 3、4 项直接改变了结论的表述方式：不再给单一 P90 承诺，而是给"设计点邻域 P90 + 材料规格 + 95% 置信下界"三件套。

## 8. 书生（Huginn）引擎为什么没跑，以及怎么重放

沙箱没有任何 LLM 凭据，`huginn/config.py` 的 provider 需要 key 才能初始化；`run_cognitive_driver.py` 会直接失败。**我没有伪造运行结果**。

提供任一可用 key 后即可重放：

```bash
cd /workspace/agent
export HUGINN_PROVIDER=deepseek HUGINN_MODEL=deepseek-v4-flash DEEPSEEK_API_KEY=<key>
export WORKSPACE_DIR=/workspace/research/shusheng_run/ws30_llm
PYTHONPATH=. /workspace/venv/bin/python -m huginn.run_cognitive_driver "$(cat /workspace/research/shusheng_run/objective_ws30.txt)" 50
```

验收锚点（来自本报告，可逐条比对）：

- 必须有能量守恒账本且残差 < 1e-8；
- 必须给出 t90 的网格与时间步收敛阶（≈1）；
- 必须报告删失比例，且 P90 不可辨识时不能硬给数字；
- 必须区分"设计空间先验 UQ"与"设计点邻域 UQ"；
- 必须给出可承诺的材料容差规格及其置信下界。
