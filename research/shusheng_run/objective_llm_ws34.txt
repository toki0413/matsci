目标：从一份**生成机制未公开**的基准数据集反演 MgH2 脱氢动力学，判定"球状 Fick 扩散"模型是否成立，并给出带不确定性的可证伪预测。至少 50 个真实循环（每个循环 = 一次真实执行 + 可核对数值），交付代码、结果与报告。

数据（只读，不要修改）：data/benchmark_t50.csv
- 75 行，表头 temperature_K,radius_m,t50_s
- 温度 500–700 K，半径 1e-7–1e-5 m，每个 (T,r) 组合 3 次重复，含测量噪声
- **生成机制未公开，不要假设它由球状 Fick 扩散生成**

必须回答的四个问题：
Q1 温度依赖的活化能 Ea 是多少（点估计 + 95% 置信区间）。
Q2 t50 对半径 r 的标度指数 p 是多少（点估计 + 95% 置信区间），即 t50 ∝ r^p。
Q3 球状 Fick 扩散模型（解析解 F(t)=1-(6/pi^2)sum(1/n^2)exp(-n^2 pi^2 D t/r^2)，其推论是 p=2 且 t50=0.030547 r^2/D）能否解释这批数据？必须用拟合残差与信息准则（AIC 或 BIC）给出定量结论，不能只说"大致吻合"。
Q4 给出一个可被证伪的预测：明确写出预测公式、一个具体工况（例如 T=650 K、r=2e-6 m）的预测值 ± 区间，以及"若实测落在什么范围之外则模型被推翻"。

循环定义（硬性）：
- 50 个循环 = 对 75 行数据做 50 次 bootstrap 重采样（有放回，固定随机种子），每次重采样都真实重跑一遍完整拟合（Ea、p、以及 Q4 的预测值），把该次的数值写进 loop_log.jsonl。
- loop_log.jsonl 每行一个 JSON 对象，至少含：loop_id（1..50）、status、r_exponent、Ea_kJ_per_mol、t50_pred_650K_2um_s。
- loop_log.jsonl 少于 50 行时不要收结，继续做下一个循环。

独立校验（硬性）：
- 主结果必须用两种独立方法交叉验证：log-log 线性回归（对 Ea 也可用 ln t50 vs 1/T）与非线性最小二乘（scipy.optimize.curve_fit 或 least_squares），给出两种方法结果之差。
- 必须对 Fick 模型单独做一次拟合（把 D0、Ea 作为自由参数），报告其残差标准差、以及 ΔAIC（相对被选模型）。若 Fick 被拒，要写清拒绝的依据。

执行环境说明（照做，别浪费轮次）：
- 用 file_write_tool 写 .py 脚本，再用 bash_tool 以 argv 列表执行 `python3 <脚本>`；bash_tool 的 command 必须是数组（如 ["python3","analysis.py"]），不能是字符串。
- 只可用 numpy 与 scipy，没有 pandas、matplotlib。不要 pip install 外网包。
- code_tool 的沙箱禁止 import os、禁止 open()，不要用它读文件或跑脚本。
- 外网不可用（web_search 会失败），不要反复重试联网检索。

硬要求：
1. 必须真写代码并真实执行；禁止只交付文档、计划或空框架；禁止用随机数伪造"观测值"；禁止把拟合出来的数说成文献实测值。
2. 报告必须明确区分「数据支持的」与「仍属假设的」；数据来源在报告里必须写"基准数据，生成机制未公开"。
3. 若结论是 Fick 模型被拒，必须给出支持替代机制的定量证据（p 的置信区间是否排除 2）。
4. 报告中引用的每一个数值都必须能在 results.json 中找到（键名清晰、可逐项核对）。
5. 报告必须给出"下一步最该做什么"，且指出本研究的结论在什么条件下会不成立。

交付物：
