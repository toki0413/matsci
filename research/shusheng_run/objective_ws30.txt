任务：基于 design_solid_h2.md（固态储氢系统人工智能辅助设计总体方案），自主选择当前算力下能真正推进的一环，把固态储氢（MgH2 床层吸氢）的一个环节做成可运行、可验证的研究，并至少完成 50 个真实循环。

约束与环境：
- 只有 numpy / scipy / pandas，单机 CPU，无 GPU、无网络下载。
- 数据只能来自公开物理定律/物性关系（代码写明公式或出处）或由这些方程数值求解得到的真解。禁止随机数伪造观测值，禁止把常数写成"实测值"。
- 至少做一次独立校验：换方法、换离散分辨率、或取极限情形。

硬要求（验收锚点）：
1. 必须有能量守恒账本，相对残差 < 1e-8。
2. 必须给出 t90 的网格收敛阶与时间步收敛阶（预期 ≈1）。
3. 必须报告删失比例；P90 不可辨识时不得硬给数字，必须用 Kaplan-Meier 或等价口径并说明。
4. 必须区分"设计空间先验 UQ"与"设计点邻域 UQ"，并说明为什么单一 P90 对混合分布没有决策含义。
5. 必须给出可承诺的材料容差规格及其单侧置信下界（不得用 n=12 的点估计当结论）。

交付物（落盘）：
1. prototype/ 下可重复运行代码（固定随机种子）
2. results.json：报告引用的每个数值都能在其中找到
3. report.md：六节（选题与取舍 / 对应方案条款 / 真实结果 / 简化与不成立之处 / 独立校验 / 下一步），并明确区分"已验证"与"未验证/假设"
4. loop_log.jsonl：逐循环台账
