# 研究计划: 第一性原理 (DFT) 筛选 SiC 多型体 3C/4H/6H 的带隙与结构稳定性

> 状态: 草案 v1 | 创建: 2026-08-14 | 阶段: Literature Review → PLANNING
> 执行环境约束: 本沙箱未安装 VASP/QE/CP2K, 以下参数为知识库经验值, 落地前须经 Phase 0 文献/数据库核实。

---

## 0. 目标与范围

用 DFT 对 SiC 三种最常见多型体做带隙 + 结构稳定性筛选:

- **3C-SiC** (闪锌矿, F-43m, 原胞 2 原子, 堆垛 ABC)
- **4H-SiC** (六方, P6₃mc, 原胞 8 原子, 堆垛 ABCB)
- **6H-SiC** (六方, P6₃mc, 原胞 12 原子, 堆垛 ABCACB)

**输出**: 每多型体的平衡晶格参数、体弹模量、形成能、高于凸包能量 (E_hull)、带隙类型与数值 (PBE/HSE06/G0W0 三档)、声子稳定性判定; 最终给出"带隙 vs 稳定性"排序表。

**明确不做**: 缺陷/掺杂、表面、热输运、激子效应 (BSE)、温度效应 (除声子零点外)。【第 6 轮修订: "温度效应"的边界需放宽 — L6/L7 已把有限温度自由能列入研究问题; 至少 Phase D 需加做声子 DOS 的低频段对比, 以裁决 H8】

---

## 1. 科学问题与假设 (筛选判据的候选)

同时保留以下假设, 由数据裁决, 不预先收敛到单一结论:

- **H1 (带隙排序)**: 带隙满足 3C < 6H < 4H (实验 ~2.36 / 3.02 / 3.23 eV)。若 HSE06 复现排序且绝对偏差 < 0.15 eV, 则 HSE06 单点即可作为筛选终点, 无需 GW; 若偏差 > 0.3 eV, 升级 G0W0。
- **H2 (稳定性排序与精度门槛)**: 能量排序 3C < 4H ≈ 6H, 但 4H/6H 相对 3C 仅高 ~1–3 meV/atom。若 DFT 能量差与声子零点能修正同量级, 则"稳定性排序"在 0 K 意义上不可判 → 需报告能量差 + 不确定度, 而非硬排序。
- **H3 (泛函修正的转移性)**: PBE 对三种多型体的带隙低估量近似为常数 (~0.9–1.0 eV, "scissor 假设")。若成立, 筛选期可只用 PBE + 常数修正, HSE06/G0W0 仅作 3 个校准点; 若不成立 (低估量随多型体变化), 则必须全程 HSE06。

备选交叉假设 (低优先级, 记录在案):
- **H4**: 4H/6H 的 c/a 与内参量 u 对截断能/范德华处理的敏感性高于 3C, 导致体积与体弹模量的伪差异 → 用于解释 Phase B 的 EOS 结果, 防止把数值伪影当物理。

第 3 轮补充 (2026-08-14, 基于记忆值内部自洽校验 + 解析/数值论证, 待 Phase 0/Phase C 核实; 第 4 轮已合并第 2 轮重复条目):
- **H5 (双层/六方 a 不变量)**: 3C 的六方化表示 a_h = a_c/√2 = 3.083 Å, 与 4H (3.073)、6H (3.081) 仅差 0.3%; 双层间距 3C/4H/6H = 2.517/2.513/2.520 Å (spread 0.25%), Si-C 键长 = 1.888/1.882/1.887 Å (spread 0.3%)。多型体 (a,c) 差异是同一双层以不同序列堆叠的几何投影, 而非键合化学变化 → 预测: 任何 SiC 多型体双层间距 ∈ 2.517 Å ±0.3%; Phase B 弛豫后直接检验。
- **H6 (六方度-能量线性 / ANNNI 映射)**: ΔE(多型体) ≈ J·h (h=六方度: 3C=0, 6H=1/3, 4H=1/2, 2H=1), J ≈ 2.5 meV/atom (记忆估计), 即 ANNNI 单 J₂ 图像 (跨域: 磁性系统 → 半导体多型体)。Phase D 能量差裁决; 若偏离, 需引入 J₃/应变耦合。注意与带隙不同: 经验带隙 E_g(h) 是**亚线性** (斜率 1.98→1.74→0.97 eV/h, 饱和), 带隙不是 h 的线性函数。**3C 是 0 K 基态, 但 6H 是商业上最常见的生长多型体 → 温度/熵效应必须显式声明, 不能把 0 K 排序直接当"工业稳定性"。**
- **H7 (带隙排序机制: 3D 折叠, 而非应变/二聚化)**: 排除两机制 — (i) 应变: 六方 a 只差 0.3%, 应变贡献几十 meV ≪ 带隙差 0.66–0.87 eV; (ii) 二聚化: 层间距守恒 → 跃迁变化 ~1% → 隙 ~20 meV。负结果: 1D on-site toy 模型给出 4H(0.80t) < 6H(1.22t), 与实验 4H>6H 相反, 且 3C/2H 均为金属 — 1D 代理不可用。修正: 初始猜测"3C 的 X 点折叠到 4H/6H 的 M 点"被数值否定 (X 折叠到六方 BZ 的 Γ 面 (0.5,0.289,0); M 点在立方 BZ 对应非特殊点 (0.21,0.31,0.40)) → 真实机制 = 沿 c 折叠 + 堆垛势混合 + 晶体场劈裂, 必须用 Phase C 的展开能带 (unfolded bands)/fat-band 分析验证, 并复现 E_g(h) 亚线性 (斜率 1.98/1.74/0.97 eV/h) 这一定量约束。

第 6 轮补充 (2026-08-14, Debye 模型定量 + 对 L6 的机制纠错, 待 Phase D 声子谱核实):
- **H8 (振动熵稳定化)**: 六方多型体沿 c 有更软的堆垛相关声学模 → θ_D(4H/6H) 略低于 θ_D(3C) → 高温下 4H/6H 振动熵更高。Debye 定量: ΔS_vib ≈ 3k_B(Δθ_D/θ_D); 若 Δθ_D/θ_D ∈ 0.3–1%, T=1500–2500 K 时 T·ΔS ≈ 1–6 meV/atom, 与 ΔE(0 K) ≈ 0.8–1.3 meV/atom 同量级甚至更大 → 生长温度下 4H/6H 可在自由能上反超 3C。裁决路径: Phase D phonopy 声子 DOS 低频段 (0–10 THz) 对比 + 准谐自由能 F(T)。
- **L6 纠错 (重要)**: 第 5 轮"1D 堆垛熵 ln2/双层"论证有概念错误 — **完美周期多型体 (3C/4H/6H) 的组态熵 = 0**, ln2 熵只适用于"随机堆垛/堆垛无序", 不能解释 6H 的工业偏好。有限 T 稳定性只能来自 (i) 振动熵 (H8, 热力学) 或 (ii) 生长动力学 (Frank 螺旋位错复制机制、台阶流、杂质效应, 非热力学)。第 5 轮"300 K 翻转"的结论作废, 保留"报告必须区分 0 K 与有限 T 两张表"的要求。

## 2. 计算框架与参数 (VASP 6.x, PAW)

| 项目 | 取值 | 说明 |
|---|---|---|
| 泛函 | PBE (结构/声子) + HSE06 (带隙单点) + G0W0@PBE (可选校准) | PBE 低估带隙 ~1 eV; HSE06 对 SiC 精度 ~0.1 eV |
| 截断能 ENCUT | 520 eV (收敛扫描 400/520/650) | C 的 PAW 需要高截断; 三体系必须同一 ENCUT 才能比能量 |
| k-mesh (Γ-centered) | 3C: 8×8×8; 4H: 6×6×4; 6H: 6×6×3; 收敛扫描各加一档 | 按原胞倒空间等密度取; 能量差分辨目标 0.5 meV/atom |
| smearing | ISMEAR=0, SIGMA=0.05 (半导体) | 严禁金属 smearing 用于能量对比 |
| 收敛判据 | EDIFF=1e-6 eV, EDIFFG=-0.01 eV/Å, ISIF=3 | 全弛豫 (离子+晶胞) |
| 能量参考 | Si(金刚石) + C(金刚石) 各自全弛豫 | 形成能 E_form = E(SiC) − E(Si) − E(C), 按 SiC 对归一 |
| 声子 | phonopy 有限位移法 + VASP; 超胞 3C: 2×2×2(16 原子), 4H: 2×2×1(32), 6H: 2×2×1(48) | 判动态稳定性 (虚频); 超胞截断能/力收敛必须严格 |
| EOS | Birch-Murnaghan 4 参数拟合 V(E) | 得 V₀, B₀, B₀′ |
| 能带路径 | 3C: Γ–X–W–K–Γ–L; 4H/6H: Γ–M–K–Γ–A–L–H | 三体系都间接带隙, VBM/CBM 不在 Γ, 必须跑完整路径 |

**结构来源**: 优先从 Materials Project API / ICSD 拉取实验/弛豫结构 (3C: mp-8062 附近条目; 4H/6H 条目 ID 需在 Phase 0 核实), 手建坐标仅作交叉验证。
⚠️ 已有 `/Si_diamond/POSCAR` 的 a=4.43 Å 与实验 5.43 Å 不符, 用作 Si 参考前必须重新弛豫并核实 (疑似旧文件少写一位或未收敛)。

## 3. 执行步骤 (每阶段有验证门)

### Phase 0 — 文献与数据库基准 (0.5–1 周, 只读)
- [ ] `literature_tool.benchmark_lookup`: 收集 3C/4H/6H 的实验带隙、晶格常数、体弹模量、多型体能量差 (≥10 篇, 记录文献 spread)
- [ ] Materials Project 拉取三结构 + mp 能量, 与实验晶格对比
- [ ] 核实/修正 `/Si_diamond/POSCAR`, 备好 C(金刚石) 参考结构
- **门 G0**: 文献基准表就绪; 晶格常数与实验偏差 < 2% 才放行; 若 Phase 0 发现本计划参数与文献冲突, 回改本文件 (版本化)。

### Phase A — 收敛测试 (0.5 周, 3C 小体系)
- [ ] ENCUT × k-mesh 双扫描 (3C 原胞 2 原子, 极便宜), 定出全局一致参数
- **门 G1**: 能量收敛 < 1 meV/atom (ENCUT 与 k-mesh 两轴都满足); 记录并锁定参数, Phase B–D 不改参数。

### Phase B — 结构优化 + EOS (1 周)
- [ ] 三体系 ISIF=3 全弛豫; 输出 a, c, u (内参量)
- [ ] V(E) 曲线 5–7 点 → Birch-Murnaghan 拟合 → V₀, B₀
- **门 G2**: 晶格常数 vs 实验 < 1%; B₀ 落在 200–230 GPa 区间 (文献 ~224 GPa); 否则查 U/泛函/截断, 不继续。

### Phase C — 能带与带隙 (1 周)
- [ ] PBE 能带: 确定带隙类型 (间接) 与 VBM/CBM k 点; 三体系 PBE 带隙
- [ ] HSE06 单点 (PBE 几何): 三体系带隙
- [ ] (可选) G0W0@PBE: 至少 3C 一个校准点
- **门 G3**: HSE06 vs 实验 |Δ| < 0.15 eV 则 H2/H3 判据生效; PBE 低估量若非常数 (>0.2 eV 变化), 触发 H3 分支: 全程 HSE06。

### Phase D — 稳定性: 形成能 + 声子 (2 周, 最贵阶段)
- [ ] E_form (三体系, 同参数) + E_hull (相对 3C 的 ΔE)
- [ ] phonopy 声子谱: 无虚频 → 动态稳定; 有虚频 → 标记亚稳/失稳并定位软模
- [ ] 零点能修正 ΔE_ZPE (声子计算自带), 评估是否翻转 H2 的能量排序
- **门 G4**: ΔE(4H−3C) 的不确定度 (k-mesh/ENCUT 收敛残差) 量化上报; 若 |ΔE| < 不确定度, 结论写"能量简并, 不可区分", 不硬排序。

### Phase E — 汇总、对标、报告 (0.5 周)
- [ ] 排序表: 每行 = 多型体; 列 = a, c, u, V₀, B₀, E_form, E_hull, E_gap(PBE/HSE06/G0W0/实验), 声子稳定性, ΔE_ZPE
- [ ] 带隙-稳定性 Pareto 图; H1–H4 逐条判定 (支持/拒绝/证据不足)
- [ ] 代码、POSCAR、INCAR 模板、数据归档到工作区
- **门 G5**: 全部判定基于门 G0–G4 数据, 无未标不确定度的结论。

## 4. 关键陷阱 (每个都是常见翻车点)

1. **能量差太小**: 4H/6H vs 3C 仅 ~1–3 meV/atom → 任何 k-mesh/smearing/ENCUT 不一致都会伪造排序。对策: 三体系共享同一参数组 + 收敛残差显式上报。
2. **间接带隙误判**: 只算 Γ 点会得到错误带隙值/类型。对策: 完整高对称路径 + 显式定位 VBM/CBM。
3. **半导体 smearing 污染**: 金属 smearing 会让半导体能量差失真。对策: ISMEAR=0。
4. **声子超胞收敛**: 48 原子的 6H 超胞若力收敛不严, 会出现伪虚频。对策: EDIFFG 提到 −0.005 eV/Å。
5. **PBE 带隙系统性低估被当物理**: 筛选排序可用 PBE, 报数值必须标泛函。
6. **手建坐标内参量错误**: 4H/6H 的 u 参数写错会直接污染结构。对策: 以数据库结构为准。
