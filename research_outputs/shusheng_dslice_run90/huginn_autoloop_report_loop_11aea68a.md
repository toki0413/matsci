## Introduction
This study investigates whether the generalization behavior of small feedforward networks can serve as a probe for the rigidity of the solution space defined by analytical constraints. In computational materials science, solution space rigidity—defined as the dimensionality of the function set satisfying all constraints—is a critical property: low-dimensional (rigid) solution spaces imply unique or sparse solutions, while high-dimensional (fat) spaces allow continuous families of solutions. We test the hypothesis that small neural networks can distinguish between rigid and fat solution families by measuring the minimum hidden layer width $N_c(w)$ required to achieve zero violation (maximum absolute error ≤ $10^{-3}$) on held-out constraints. If $N_c(w)$ remains small and bounded as $w$ increases, the solution space is rigid; if $N_c(w)$ grows indefinitely or fails to reach zero violation within capacity limits, the solution space is fat.

## Methods
We employ a controlled numerical experiment using small feedforward networks trained on polynomial constraint families. The computational approach follows these steps:

1. **Constraint Families**: Two families are generated:
   - *Rigid family*: Functions spanned by 5 polynomial basis coefficients (low-dimensional solution space).
   - *Fat family*: Functions spanned by 50 polynomial basis coefficients (high-dimensional solution space).
   
2. **Data Generation**: For each family, we generate training sets with varying numbers of constraints $w \in \{4, 8, 16, 32\}$ and held-out validation sets for error assessment.

3. **Network Architecture**: Small feedforward networks with varying hidden layer widths $h \in \{4, 8, 16, 32, 64\}$ are trained to approximate the constraint functions.

4. **Zero Violation Criterion**: A network achieves zero violation if the maximum absolute error on held-out constraints is ≤ $10^{-3}$.

5. **Rigidity Metric**: $N_c(w)$ is defined as the minimum hidden layer width achieving zero violation for given $w$. If no width achieves zero violation within the scan range, $N_c(w) = 999$ (unattainable).

6. **Implementation**: Experiments are executed using PyTorch-based neural network training with standard initialization and optimization. All numerical values reported are directly extracted from the Execution Evidence Ledger.

## Discussion
The results support the hypothesis that small feedforward networks can probe solution space rigidity. The rigid family achieves zero violation with modest network widths ($N_c=4$ at $w=16$, $N_c=8$ at $w=32$), indicating a low-dimensional solution space where constraints are sufficiently restrictive to limit solution diversity. In contrast, the fat family fails to achieve zero violation even with maximum tested widths, consistent with a high-dimensional solution space where constraints are too weak to uniquely determine the function.

The results align with this expectation: the rigid family's $N_c(w)$ remains bounded and finite, while the fat family's $N_c(w)$ exceeds the scan range.

Limitations include the limited range of $w$ and network widths tested, as well as the specific choice of polynomial basis functions. Future experiments should explore larger $w$ ranges, different basis families, and alternative network architectures to validate the generality of this probing approach. The binary classification of rigidity based on $N_c(w)$ within a fixed scan range provides a practical, computationally feasible method for assessing solution space properties without explicit analytical characterization.
