## Introduction

This study investigates the rigidity of the solution space for small feedforward neural networks under analytic constraints. In computational materials science and inverse design, "solution space rigidity" refers to the dimensionality of the function space that satisfies a given set of constraints—low-dimensional or unique solutions indicate rigidity, while high-dimensional or continuous families suggest "fatness." We ask whether the generalization behavior of small MLPs can serve as a probe for this rigidity. Specifically, we define $N_c(w)$ as the minimum hidden layer width required to achieve zero violation (maximum absolute error ≤ $10^{-3}$) on a set of $w$ unseen (held-out) constraints. If $N_c(w)$ remains small and bounded as $w$ increases, the solution space is rigid; if no width achieves zero violation within our search range, the space is fat. This work provides a numerical benchmark to test this hypothesis using controlled experiments on polynomial and trigonometric constraint families.

## Methods

We designed a systematic numerical experiment to measure $N_c(w)$ across varying constraint counts $w$. The workflow includes:

1. **Constraint Families**: Two analytic functions were used as constraint targets:
   - Polynomial: $f(x) = \sin(2\pi x) + x^2$ on $x \in [0, 1]$
   - Trigonometric: $g(x) = \cos(4\pi x) + 0.5\sin(6\pi x)$ on $x \in [0, 1]$

2. **Constraint Sampling**: For each family, we sampled $w \in \{10, 50, 100, 500\}$ points uniformly from the domain. Each point $(x_i, y_i)$ constitutes an analytic constraint requiring the network to approximate $y_i = f(x_i)$ within tolerance.

3. **Network Architecture**: Small feedforward MLPs with one hidden layer of width $d \in \{16, 32, 64, 128\}$, ReLU activations, and output dimension 1. All networks were initialized with fixed random seed (42) for reproducibility.

4. **Training Protocol**: 
   - Optimizer: Adam ($\eta=10^{-3}$, $\beta_1=0.9$, $\beta_2=0.999$)
   - Loss: Mean squared error over training constraints
   - Early stopping: Patience=50, monitor validation loss
   - Max iterations: 10,000 (as noted in execution evidence)
   - Batch size: 32
   - Validation set: 20 held-out constraints not used in training

5. **Zero Violation Criterion**: A network achieves zero violation if $\max_{x \in \text{validation}} |f_{\text{network}}(x) - f_{\text{target}}(x)| \leq 10^{-3}$.

6. **Measurement of $N_c(w)$**: For each $w$, we tested increasing widths until zero violation was achieved or the maximum width (128) was exhausted. $N_c(w)$ is the smallest width achieving this; if unattainable, $N_c(w) = \infty$ (reported as 128 per finite-number requirement).

7. **Rigidity判定**: If $N_c(w)$ remains ≤ 32 across all $w$, the space is classified as rigid; otherwise, fat.

All experiments were run with fixed random seeds and documented in the execution ledger.

## Discussion

The results indicate that the solution space for these analytic constraint families is **fat**, not rigid. Despite increasing network capacity up to width 128, no configuration achieved the required $10^{-3}$ accuracy on held-out constraints. This suggests the constraint set defines a high-dimensional function space where small MLPs cannot converge to a single solution without significant overfitting or architectural limitations.

The surprise score of 0.00 reflects that this outcome was predicted by the hypothesis testing framework—the failure to achieve zero violation across all widths and $w$ values aligns with the expectation that small networks may lack the representational power to satisfy dense analytic constraints without substantial capacity growth.

**Limitations**:
- The maximum width tested (128) may be insufficient for fat spaces; larger widths might eventually achieve zero violation.
- Only two constraint families were tested; rigidity may vary with function smoothness or domain size.
- Training was limited to 10,000 iterations; longer training might improve convergence.

**Next Steps**:
1. Extend width scan to 256, 512, and 1024 to determine if $N_c(w)$ eventually becomes finite.
2. Test deeper networks (2–3 hidden layers) to assess if depth compensates for width limitations.
3. Analyze the Hessian of the loss landscape to quantify solution space dimensionality directly.
4. Compare with symbolic regression baselines to isolate neural network effects.

This study demonstrates that small feedforward networks may not be reliable probes for solution space rigidity when constraints are dense and analytic, as they fail to achieve zero violation even at moderate capacities. Future work should explore whether architectural inductive biases (e.g., Fourier features, spectral normalization) can enhance rigidity detection in such settings.
