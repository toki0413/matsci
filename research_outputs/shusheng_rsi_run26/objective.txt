【研究命题·纯机器学习/数学】

解空间刚性 = 满足全部解析约束的函数集合的维数：低维/唯一 = 刚，高维/连续族 = 胖。

核心问题：小型前馈网络的“泛化行为”能否作为 bootstrap 解空间刚性的探针？
令 w = 约束样本数，N_c(w) = 在未参与训练的留出约束点上取得“零违规”所需的最小网络容量（用隐藏层宽度度量）。测量 N_c(w) 随 w 的趋势：
- 不增（小容量即可零违规）→ 支持刚性（唯一性/低维）；
- 递增（样本越多越装不下）→ 支持胖（高维/连续族）。

研究对象只能是小型前馈网络本身。硬性边界：严禁把本命题替换或“换名归约”为材料、化学、玻璃、合金、离子导电等任何物理体系，也不要用别的领域类比回答。

【零违规判据·统一口径（务必遵守）】
- 零违规 = 在未参与训练的留出约束点上，最大绝对误差 ≤ 1e-3。
- 训练误差只需“足够小”（例如 ≤1e-4）即可，**不要额外加 train_err < 1e-6 这类过严门槛**——它会把本来可达的宽度也判成失败，制造伪“不可达”。
- 所有报告数值必须是有限数（禁止 inf / nan / None）：某行若达不到零违规，就如实报该行真实的（有限）留出误差，不要写 inf。

【第 0 步·零违规可达性 bootstrap（必须先做，否则整轮无效）】
在测 N_c(w) 之前，先证明“零违规在本实验里是可达的”：构造一个足够容易的子问题（例如低维线性/低维唯一解约束族 + 足够宽的网络），让某个 (w, 宽度, 种子) 组合训练后对留出点达到零违规，并把这个“可达锚点”的数值（宽度、训练误差、留出误差）如实打印出来。
- 若在最大宽度下仍无法零违规，先调优化器/起点/训练规模再重做；此时不得报 N_c(w)，也不得把“未收敛的低值”当作刚性证据。

【实验设计·可复现数值实验】
1) 真的训练网络：用 scipy.optimize.minimize(method='L-BFGS-B') 最小化训练集 MSE 去找能零违规的最小宽度；手写 numpy 梯度下降通常收敛不到 1e-3，不要用它当主优化器。
2) 多起点：每个宽度用 ≥3 个随机起点各优化一次取最优，避免优化器落到局部极小、把可达宽度误判为不可达。
3) 宽度扫描要留足上限，并保证扫描范围内确实存在零违规的宽度（由第 0 步保证可达）；若整段扫描全部触顶，说明实验无效，必须改约束族或提高上限后重做。
4) 趋势判据必须区分“非增”与“递减”：全相等应报“持平(flat)”，不是 decreasing。报告必须给出真实 N_c(w) 数值表，以及每行的训练误差 / 留出误差（都是有限数）。
5) 至少 3 个随机种子，报告 N_c(w) 的均值±标准差，并说明约束族的构造依据（低维/刚性与高维/胖各对应什么解析 ground truth）。

【Code Lab 脚本契约（脚本必须满足，否则跑不通）】
- 沙箱**已内置完整数值管线** capacity_scan(family, ...)：训练（两层 tanh + L-BFGS-B 多起点）/宽度扫描/零违规判据/N_c 汇总 都由它完成。
- 你**只需实现 family(kind, w, seed) 这一个函数**（定义 rigid/fat 各自的约束族数据，这是真正需要你决策的科学部分），run(cfg) 原样 `return capacity_scan(family, seed=...)`。
- **不要改 run 函数，也不要把训练/优化/参数打包/前向传播写进代码**——那正是反复形状报错的根源，已验证在本环境里必错。
- family 返回 dict {'X','y','Xv','yv'}：X/y 是 w 个**训练**约束点，Xv/yv 是**留出**约束点；X/y/Xv/yv 一律用 .reshape(-1, 1) 升成 (N,1)。
- **留出集必须真的留出**：Xv 的输入点不能与 X 的任何训练点重合（否则“留出误差”=训练误差，N_c 判据失效；脚手架会判 trend='invalid_heldout' 并在 warnings 里报重叠比例）。Xv 请用不同的网格或不同采样点。
- 随机数用 rng = np.random.default_rng(seed)；Generator **没有** randn，用 rng.standard_normal(n)。
- 不要用 assert / raise 中断执行：把测到的真实数值（含不理想的结果）全部 return，由上层裁决。

所有结论必须来自真实运行的可复现数值实验：给出扫描设置、训练与留出误差的数值、以及 N_c(w) 的数值与趋势。
