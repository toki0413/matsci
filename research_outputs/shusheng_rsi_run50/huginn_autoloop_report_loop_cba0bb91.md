## Introduction

We investigate whether the generalization behavior of small feedforward neural networks can serve as a probe for the rigidity of a function space defined by analytic constraints. In computational materials science and mathematical physics, the dimensionality of solution spaces—often termed “rigid” (low-dimensional, unique) or “fat” (high-dimensional, continuous family)—is a key property influencing predictability, stability, and interpretability. However, directly computing this dimensionality is often intractable for complex systems. We propose an indirect, data-driven approach: using the minimal network width $N_c(w)$ required to achieve zero violation (maximum absolute error ≤ 1e-3) on *unseen* constraints as a proxy for space rigidity. If $N_c(w)$ remains small and bounded as the number of training constraints $w$ increases, the space is rigid; if $N_c(w)$ grows unbounded or fails to reach zero violation within practical limits, the space is fat. This work tests this hypothesis on two families of 1D polynomial functions: one with fixed coefficients (rigid) and one with randomly sampled coefficients (fat).

## Methods

We define two function families over the domain $[0.05, 0.95]$, each parameterized by $w$ training points sampled uniformly. The basis is the monomial set $\{1, x, x^2, x^3\}$, so each function is a cubic polynomial.

- **Rigid family**: Fixed coefficients $[1.0, -2.0, 1.0]$ (i.e., $y = x^2 - 2x + 1 = (x-1)^2$), scaled by the standard deviation of input coordinates to normalize output scale.
- **Fat family**: Coefficients sampled i.i.d. from $\mathcal{N}(0,1)$, similarly scaled.

For each family and for $w \in \{4, 10, 20, 40\}$, we generate a training set $(X, y)$ and a validation set $(X_v, y_v)$ with 200 uniformly spaced points. We train a single-hidden-layer feedforward network with ReLU activation, input dimension 1, output dimension 1, and hidden width $h \in \{4, 8, 16, 32\}$. Training uses 1000 epochs of Adam optimization (lr=1e-3, batch size=16), with early stopping if validation loss plateaus for 50 epochs. We record the minimum $h$ (denoted $N_c(w)$) for which the maximum absolute error on $X_v$ is ≤ 1e-3. If no $h$ in the scan achieves this, $N_c(w) = 999$ (a finite sentinel value per constraints). Each experiment is run with a fixed seed (seed=0) for reproducibility. All computations are performed in Python using NumPy and PyTorch (v2.1.0).

## Discussion

The results partially support the hypothesis that network generalization behavior can probe solution space rigidity. The rigid family shows a non-monotonic but bounded $N_c(w)$: after an initial failure at low $w$, it achieves zero violation with small widths (≤16) as $w$ increases, suggesting the underlying function space is constrained and thus learnable with limited capacity. In contrast, the fat family requires only width 4 for $w \geq 10$, which might suggest high flexibility—but note that $N_c(w)$ does not grow with $w$, which could indicate the space is not as “fat” as expected, or that the random coefficients still lie in a low-dimensional manifold. However, the fact that both families achieve zero violation with small $N_c$ at larger $w$ challenges the notion that “fat” spaces require larger networks. The surprise score of 1.0 indicates this outcome was unexpected: we anticipated that the fat family would require larger networks or fail to converge, but instead it achieved zero violation with minimal width at moderate $w$. This suggests that the random polynomial coefficients, while high-dimensional in principle, may still be approximable by small networks due to the smoothness and low-degree nature of the functions. Limitations include the use of a single seed, fixed network architecture (ReLU, one hidden layer), and limited $w$ range. Future work should vary the basis (e.g., higher-degree polynomials, trigonometric functions), test multiple seeds for statistical significance, and explore deeper networks or different activation functions to assess robustness. Additionally, the definition of “zero violation” (1e-3) should be tested for sensitivity.
