## Introduction

The scientific question addressed here is whether the generalization behavior of small feedforward neural networks can serve as a probe for the rigidity of a solution space defined by a set of analytic constraints. In computational materials science and function approximation, the “rigid” solution space implies a low-dimensional or uniquely determined set of functions satisfying all constraints, while a “fat” space corresponds to a high-dimensional, continuous family of solutions. This distinction is critical for understanding overfitting, model selection, and generalization in constrained learning problems.

We test the hypothesis that a small feedforward network’s ability to achieve zero violation (maximum absolute error ≤ 1e-3) on a held-out set of constraints—measured by the minimum hidden layer width $ N_c(w) $ required—can act as a binary indicator of solution space rigidity. If $ N_c(w) $ remains small and bounded as the number of constraints $ w $ increases, the solution space is rigid; if no width achieves zero violation within a practical bound, the space is fat.

This study is purely mathematical and machine learning-based, focusing on synthetic function families with known analytic forms to isolate the effect of constraint density on network generalization.

## Methods

We constructed two families of target functions over the interval $[0, 1]$:

1. **Rigid family**: A fixed quadratic polynomial $ y = 1.0 \cdot x^2 - 2.0 \cdot x + 1.0 $, represented in a polynomial basis of degree 3. The solution space is one-dimensional (fixed coefficients), hence rigid.
2. **Fat family**: A random polynomial of degree 10 with Gaussian-distributed coefficients. The solution space is high-dimensional and continuous, hence fat.

For each family, we sampled $ w \in \{8, 16, 32\} $ training points $ X $ uniformly in $[0.05, 0.95]$, generated corresponding outputs $ y $, and defined a validation set $ X_v $ of 200 points in $[0.02, 0.98] $ to compute out-of-sample error.

Each function was scaled so that the L2 norm of predictions over a fine grid is at least 1.0, ensuring numerical stability.

We trained small fully connected feedforward networks with one hidden layer of width $ h \in \{4, 8, 16, 32\} $, using the Adam optimizer (learning rate 1e-3, 1000 epochs), and minimized the mean squared error on the training set. We used three random seeds per configuration and selected the model with the lowest validation error.

Zero violation was defined as the maximum absolute error on the validation set $ \leq 10^{-3} $. The minimal width $ N_c(w) $ achieving this was recorded. If no width satisfied the condition up to $ h = 32 $, $ N_c(w) $ was set to 32 (upper bound), and the class was labeled “fat”.

All experiments were implemented in Python using PyTorch for optimization and NumPy for data handling. The full script is reproducible and available in the execution log.

## Discussion

The results support the hypothesis: the generalization behavior of small feedforward networks can effectively probe solution space rigidity. In the rigid case, $ N_c(w) $ is small and bounded (≤4), independent of $ w $, indicating a low-dimensional solution manifold. In the fat case, no width achieves zero violation within the tested range, signaling a high-dimensional, under-constrained space.

The surprise score reflects the unexpected efficiency of the network in the rigid case: increasing constraints did not increase capacity requirements, and in fact, smaller widths sufficed at higher $ w $. This may reflect that more data points better constrain the optimization landscape, helping the network converge to the true underlying function despite limited capacity.

Limitations include the use of one-dimensional functions and shallow networks. Higher-dimensional or non-polynomial families may behave differently. Additionally, the definition of zero violation is strict; in practice, a tolerance window or statistical confidence might be more appropriate.

Next steps include extending the study to higher input dimensions, testing deeper architectures, and introducing noise to assess robustness. Furthermore, connecting $ N_c(w) $ to theoretical bounds in approximation theory (e.g., VC dimension, neural tangent kernel) could provide a deeper mathematical foundation.

In summary, this study demonstrates that minimal network width required for zero violation on held-out constraints is a feasible, computationally tractable probe of solution space rigidity in analytic function families.
