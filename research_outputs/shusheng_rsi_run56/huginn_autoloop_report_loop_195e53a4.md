## Introduction

We investigate whether the generalization behavior of small feedforward neural networks can serve as a probe for the **rigidity of the solution space** under a set of analytical constraints. In this context, *solution space rigidity* refers to the dimensionality of the set of functions that satisfy all given constraints: a low-dimensional or unique solution space is termed “rigid,” while a high-dimensional or continuous family of solutions is termed “fat.” 

The central question is: **Can the minimal network width $N_c(w)$ required to achieve zero violation (maximum absolute error ≤ $10^{-3}$) on a set of $w$ unseen constraints act as a diagnostic indicator of solution space rigidity?** If $N_c(w)$ remains small and bounded as $w$ increases, the solution space is rigid; if no width within a practical range achieves zero violation, the space is fat.

This question is significant because it reframes a fundamental geometric property of constraint satisfaction problems—solution space dimensionality—into a measurable, machine-learnable quantity using standard neural network architectures. It offers a data-driven lens to distinguish between rigid and fat solution spaces without explicit analytical characterization.

## Methods

We define a family of synthetic constraint functions $f: \mathbb{R} \to \mathbb{R}$, each imposing $w$ point-wise equality constraints $f(x_i) = y_i$ at distinct input locations $\{x_i\}_{i=1}^w$. The constraints are generated from two distinct functional families:

1. **Rigid family**: Constraints derived from a single, low-degree polynomial (e.g., $f(x) = \sin(2\pi x)$ sampled at $w$ points). The true function is smooth and low-dimensional, implying a potentially rigid solution space.
2. **Fat family**: Constraints sampled from a high-variance, non-smooth function (e.g., a random Fourier series with decaying amplitudes), such that many distinct functions can satisfy the same $w$ constraints, implying a fat solution space.

For each family, we vary $w \in \{10, 20, 50, 100, 200, 500\}$, generating 10 random constraint sets per $w$ to assess robustness.

We train small feedforward neural networks (2 hidden layers, ReLU activation) with width $N \in \{10, 20, 30, \dots, 999\}$ on the $w$ training constraints. Training uses the Adam optimizer (learning rate $10^{-3}$, 1000 epochs), with early stopping on validation loss. The **validation set** consists of 500 unseen constraint points (distinct from training points), and **zero violation** is declared if the maximum absolute error on these points is ≤ $10^{-3}$.

$N_c(w)$ is recorded as the smallest $N$ achieving zero violation across all 10 random sets for a given $w$. If no width ≤ 999 achieves zero violation, $N_c(w) = 999$ (upper bound). All experiments are run in PyTorch with fixed random seeds for reproducibility.
