## Introduction

This study investigates whether the generalization behavior of small feedforward neural networks can serve as a computational probe for the rigidity of a constraint-defined solution space. In computational materials science and machine learning theory, "rigidity" refers to the dimensionality of the set of functions satisfying a given family of analytical constraints: a low-dimensional or unique solution set is termed "rigid," while a high-dimensional, continuous family is "fat." We hypothesize that the minimal network capacity—measured by hidden layer width $N_c(w)$—required to achieve zero violation on held-out constraints scales with the sample size $w$ in a way that reflects this underlying geometry. Specifically, if the solution space is rigid, $N_c(w)$ should decrease or remain constant as $w$ increases; if the solution space is fat, $N_c(w)$ should increase with $w$. This approach provides a model-agnostic, numerically grounded method to assess solution space topology without invoking physical analogies or material systems.

## Methods

We implemented a bootstrap rigidity probe using small fully connected feedforward networks in Python (PyTorch 1.13, NumPy 1.24). The experiment was designed to be self-contained and reproducible, with all components defined in a single script (`rigidity_probe.py`). The workflow consisted of the following steps:

1. **Constraint Family Definition**: Two abstract constraint families were used:
   - **Polynomial Interpolation**: Given $w$ data points $(x_i, y_i)$, constraints require $f(x_i) = y_i$ for a function $f: \mathbb{R} \to \mathbb{R}$. The target function was sampled from a cubic polynomial $f^*(x) = x^3 - 2x^2 + x + 1$.
   - **Convexity Inequalities**: For $w$ randomly sampled triples $(x_i, x_j, x_k)$ with $x_i < x_j < x_k$, constraints enforce the convexity condition:  
     $$
     \frac{f(x_j) - f(x_i)}{x_j - x_i} \leq \frac{f(x_k) - f(x_j)}{x_k - x_j}
     $$
     The target function was chosen as $f^*(x) = x^2$, which is strictly convex.

2. **Network Architecture**: All networks had one hidden layer with width $N \in \{2, 4, 8, 16, 32, 64\}$, ReLU activation, and a single output. Input dimension was 1; output dimension was 1.

3. **Constraint Sampling**: For each $w \in \{5, 10, 20, 40, 80, 160\}$:
   - $w$ constraint points were sampled uniformly from $[-2, 2]$ (for interpolation) or as triples from the same domain (for convexity).
   - Constraints were split into training set (80%) and held-out validation set (20%).

4. **Training and Evaluation**:
   - Each network was trained for 10,000 epochs using Adam optimizer (lr=1e-3) with MSE loss on training constraints.
   - After training, the model was evaluated on the held-out set. A "zero violation" was defined as maximum absolute deviation $< 10^{-4}$ on all held-out constraints.
   - For each $w$, we swept $N$ from 2 upward and recorded the minimal $N$ achieving zero violation on the held-out set: $N_c(w)$.

5. **Reproducibility**: All experiments used fixed random seeds (42) and were run on a single CPU core. The script includes logging of training loss, holdout violation, and final $N_c(w)$.
