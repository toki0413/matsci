## Introduction

The rigidity of a solution space—defined as the dimensionality of the set of functions that satisfy all given analytical constraints—provides a fundamental characterization of the underlying mathematical structure. A low-dimensional or unique solution space is termed “rigid,” whereas a high-dimensional or continuously parameterized one is termed “fat.” In the context of machine learning, the behavior of small feedforward networks as they absorb increasing numbers of constraints (here, labeled data points) can serve as a probe for this rigidity. Specifically, we define $ N_c(w) $ as the minimum hidden layer width required for a network to achieve zero violation on a set of $ w $ held-out constraints, after explicit optimization. If $ N_c(w) $ remains constant or decreases as $ w $ increases, this suggests a rigid solution space; if it increases, it suggests a fat one. This study investigates whether $ N_c(w) $ exhibits a phase transition indicative of a shift from a fat to a rigid regime, using small two-layer ReLU networks trained via gradient descent on synthetic linearly separable constraints.

## Methods

We employed a two-layer feedforward network with ReLU activation and a single output neuron, trained on synthetic binary classification tasks. The input dimension was fixed at 2, and the output was a binary label derived from a linear threshold: $ y = \mathbb{I}(x_1 + x_2 > 0) $. For each number of training samples $ w \in \{4, 8, 16, 32\} $, we performed a width-scan search over network widths from 2 to 64 (in steps of 1), using three random seeds per configuration to ensure reproducibility. For each width and seed, we trained the network using Adam with a learning rate of $ 10^{-3} $ for up to 500 epochs, monitoring training and validation (held-out) violation rates. A width was considered sufficient if the validation violation dropped below $ 10^{-5} $ within 500 steps. The minimal such width across seeds was recorded as $ N_c(w) $. The constraints were constructed as i.i.d. random inputs with fixed labels based on the linear rule, ensuring a deterministic ground truth. This setup allows us to distinguish between a rigid solution space (where fewer parameters suffice as data grows) and a fat one (where more capacity is needed to satisfy more constraints).
