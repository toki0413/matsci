## Introduction

The central question of this study is whether the *generalization behavior* of small feedforward neural networks can serve as a probe for the *rigidity of the solution space*—defined here as the dimensionality of the set of functions that satisfy all given analytical constraints. A low-dimensional or unique solution space (rigid) should be approximable with minimal network capacity, while a high-dimensional or continuously parameterized space (fat) would require increasing capacity to satisfy more constraints. We test this by measuring $ N_c(w) $, the minimum hidden layer width required to achieve zero violation on held-out constraints as a function of constraint count $ w $. If $ N_c(w) $ remains non-increasing with $ w $, it supports rigidity; if increasing, it supports fatness.

This question matters because it reframes the generalization capacity of neural networks not merely as a statistical learning phenomenon, but as a geometric property of the underlying constraint manifold. It offers a purely mathematical and computational lens through which to assess solution space structure without invoking physical analogies or material systems—strictly adhering to the stipulated domain.

## Methods

1. **Constraint Construction**: We defined a low-dimensional, analytically tractable constraint family: $ f(x) = \sin(\pi x) $ on $ x \in [0, 1] $, sampled at $ w $ equally spaced points. This function lies in a 1D function space (sine wave), hence the solution space is rigid—only one function satisfies all constraints exactly.

2. **Network Architecture**: We used a single-hidden-layer feedforward network with width $ h $, tanh activation, and linear output. The network was trained via L-BFGS-B (from `scipy.optimize.minimize`) to minimize mean squared error on training constraints.

3. **Zero-Violation Threshold**: A configuration achieved "zero violation" if the absolute error on all held-out constraints was $ \leq 1 \times 10^{-3} $.

4. **Width Scan**: For each $ w \in \{5, 10, 15, 20\} $, we performed a width sweep from $ h = 2 $ to $ h = 50 $ in steps of 2, using 3 random seeds per configuration. We recorded the minimum $ h $ achieving zero violation on held-out points.

Instead, the increasing trend suggests that even for a low-dimensional analytic function, the *network-induced solution space* becomes effectively "fatter" as more constraints are added—likely due to the difficulty of exactly satisfying all constraints with limited width, leading to a need for larger capacity to avoid violations on unseen points.
