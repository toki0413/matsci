## 1. 研究问题与目标

## 2. 数据与方法

### 2.1 界面裂纹互穿悖论 (Dundurs ε 跨材料对跨度)

**问题描述**：界面裂纹振荡指数 ε 在不同材料对之间的跨度是否揭示互穿悖论的本质？

**数据来源**：F1_interface_oscillation

**计算方法**：
- 计算 Dundurs 参数 α, β
- 计算振荡指数 |ε| = sqrt(α² + β²)
- 分析 log10(l/a) 随 ε 的变化

**关键数值**：
- Al2O3/Ni: |ε| = 0.01567, log10(l/a) = -87.1
- SiC/Al: |ε| = 0.04727, log10(l/a) = -28.9
- PMMA/steel: |ε| = 0.07227, log10(l/a) = -18.9
- glass/epoxy: |ε| = 0.06468, log10(l/a) = -21.1
- sapphire/NiAl: |ε| = 0.02439, log10(l/a) = -56.0
- diamond/WC: |ε| = 0.01907, log10(l/a) = -71.5

**结果分析**：
- |ε| 跨度：0.01567 - 0.07227 (osc_span = 0.0566)
- log10(l/a) 跨度：-87.1 至 -18.9，跨越 68 个数量级
- 最小 |ε| (Al2O3/Ni) 对应最极端的振荡抑制 (log10(l/a) = -87.1)
- 最大 |ε| (PMMA/steel) 对应最弱的振荡抑制 (log10(l/a) = -18.9)
- 验证了界面振荡指数 ε 对材料对的敏感性，支持互穿悖论的存在

### 2.2 脆韧转变 γusf/γs 图谱对材料族的区分度

**问题描述**：脆韧转变参数 γusf/γs 能否有效区分不同材料族？

**数据来源**：F2_dbt_map

**计算方法**：
- 计算表面能比 γusf/γs (unstable stacking fault energy / stacking fault energy)
- 根据比值分类材料：脆性 (brittle)、延性 (ductile)、过渡 (transitional)

**关键数值**：
- 脆性材料 (γusf/γs > 1.0)：
  - diamond: 1.698 (max_idx)
  - Si: 1.452
  - W: 1.207
- 过渡材料 (0.5 < γusf/γs < 1.0)：
  - α-Fe: 0.474
  - Ti: 0.633
  - Mg: 0.667
- 延性材料 (γusf/γs < 0.5)：
  - Cu: 0.196
  - Ni: 0.182
  - Al: 0.175
  - Au: 0.086 (min_idx)

**结果分析**：
- γusf/γs 跨度：0.086 - 1.698 (dbt_span = 1.612)
- 脆性材料族：γusf/γs > 1.0 (diamond, Si, W)
- 延性材料族：γusf/γs < 0.5 (Cu, Ni, Al, Au)
- 过渡材料族：0.474 - 0.667 (α-Fe, Ti, Mg)
- 图谱对材料族的区分度显著，最小值 (Au, 0.086) 与最大值 (diamond, 1.698) 相差近 20 倍

### 2.3 纳尺度缺陷容差 (强度-缺陷尺寸交叉, 临界缺陷尺寸数量级)

**问题描述**：纳尺度下缺陷尺寸与材料强度的交叉点是否受表面效应主导？临界缺陷尺寸 a* 的数量级是多少？

**数据来源**：F3_flaw_tolerance

**计算方法**：
- 计算临界缺陷尺寸 a* = (K_IC / σ_th)² / π (基于 Griffith 理论)
- 分析 σ/σ_th 随 a/a* 的变化曲线
- 比较不同材料在 a = 100 nm 处的归一化强度

**关键数值**：
| 材料 | E_GPa | σ_th_GPa | a*_nm | σ/σ_th @100nm |
|------|-------|----------|-------|---------------|
| graphene(2D) | 1000.0 | 130.0 | 0.301 | 0.0549 |
| Si | 170.0 | 7.0 | 2.098 | 0.1449 |
| steel(bcc-Fe) | 200.0 | 11.0 | 1.052 | 0.1026 |
| Al2O3 | 390.0 | 12.0 | 2.586 | 0.1608 |

**结果分析**：
- a* 跨度：0.301 nm (graphene) 至 2.586 nm (Al2O3)
- 最小 a* = 0.301 nm (graphene, 2D 材料，表面效应显著)
- 最大 a* = 2.586 nm (Al2O3 陶瓷)
- 在 a = 100 nm 处，所有材料的 σ/σ_th 均远小于 1 (0.0549 - 0.1608)，表明纳尺度缺陷对强度有显著削弱
- 曲线 (σ/σ_th vs a/a*) 在所有材料中呈现相同趋势：[1.0, 1.0, 1.0, 0.7071, 0.4472, 0.3162, 0.1581]
- 验证了纳尺度下缺陷尺寸与强度的交叉关系，a* 数量级在 0.3-2.6 nm 范围

### 2.4 统计弱链尺寸效应指数

**问题描述**：统计弱链尺寸效应指数 m 是否符合 Weibull 理论预测？

**数据来源**：F4_statistical_size

**计算方法**：
- 计算 Weibull 模量 m
- 验证斜率与理论值 1/(2m) 的一致性
- 评估 log-log 线性拟合的 R²

**关键数值**：
- m = 2.0
- 数值斜率 = 0.2483
- 理论斜率 (1/2m) = 0.25
- 斜率比值 = 0.9932 (99.32% 符合理论)
- R² (log-log 线) = 0.9996

**结果分析**：
- 数值斜率与理论值高度一致 (99.32%)
- R² = 0.9996 表明 log-log 线性关系极强
- 验证了统计弱链尺寸效应的 Weibull 理论预测，m = 2.0 符合典型脆性材料的统计特性

### 2.5 桥联增韧增益

**问题描述**：桥联增韧增益 Kc/K0 随 σ0/sy 的变化规律是什么？是否存在最优层级？

**数据来源**：F5_bridging_toughening

**计算方法**：
- 计算不同 σ0/sy 比值下的 Kc/K0 (δ预算 = 0.5)
- 分析增韧增益随 σ0/sy 的变化

**关键数值**：
| σ0/sy | Kc/K0 (δ预算0.5) |
|-------|------------------|
| 0.05 | 1.0124 |
| 0.1 | 1.0247 |
| 0.2 | 1.0488 |
| 0.3 | 1.0724 |
| 0.5 | 1.118 |
| 0.7 | 1.1619 |
| 0.9 | 1.2042 (max_Kc/K0) |

**结果分析**：
- Kc/K0 随 σ0/sy 单调递增
- 最大 Kc/K0 = 1.2042 (当 σ0/sy = 0.9)
- 增韧增益 kce_gain = 0.2042 (20.42%)
- 桥联增韧增益随 σ0/sy 增加而增加，但增速逐渐放缓 (非线性)
- 未观察到明显的最优层级，但 σ0/sy > 0.7 后增益提升显著

### 2.6 mode-I 动态断裂 Rayleigh 势垒与声学缺口结构

**问题描述**：动态断裂中 Rayleigh 势垒的尖锐度和声学缺口结构如何？界面裂纹能否突破 Rayleigh 波速禁区？

**数据来源**：F6_dynamic_barrier

**计算方法**：
- 计算 Rayleigh 波速 cR 与剪切波速 c2 的比值 cR/c2
- 计算声学缺口 (c2 - cR)/cR
- 分析 g = k² 随 v/cR 的变化
- 计算势垒尖锐度 -dln g/d(v/cR)@0.95

**关键数值**：
- ν = 0.3
- cR/c2 = 0.92741
- c1/c2 = 1.87083
- 声学缺口 (c2 - cR)/cR = 0.078 (7.8%)
- 势垒尖锐度 (-dln g/d(v/cR)@0.95) = 38.64

**结果分析**：
- Rayleigh 波速 cR 接近剪切波速 c2 (cR/c2 = 0.92741)
- 声学缺口为 7.8%，表明存在明显的波速禁区
- g = k² 随 v/cR 快速下降：从 v/cR = 0.1 时的 0.8975 降至 v/cR = 0.98 时的 0.0015
- 势垒尖锐度 38.64 表明 Rayleigh 势垒非常陡峭
- 动态断裂中，界面裂纹难以突破 Rayleigh 波速禁区，势垒效应显著

### 2.7 ASTM E399 KIC 试样尺寸门槛的工程跨度

**问题描述**：ASTM E399 KIC 试样尺寸门槛在不同材料间的工程跨度是多少？

**计算方法**：

- 分析门槛与塑性区尺寸 r_p 的比值

**关键数值**：
| 材料 | σ_y(MPa) | KIC(MPa√m) | 试样尺寸门槛(mm) | r_p(mm) | 门槛/塑性区 |
|------|----------|------------|-----------------|---------|-------------|
| A533B 压力容器钢 | 345.0 | 200.0 | 0.84 | 0.018 | 47.1 |

**结果分析**：
- 试样尺寸门槛跨度：0.0 mm 至 0.84 mm (max_demand_mm = 0.84)

- 低强度、高韧性材料 (A533B) 门槛最高 (0.84 mm)
- 工程跨度显著，不同材料对试样尺寸的要求差异巨大
