## Introduction

The central scientific question is whether the generalization behavior of small feedforward neural networks can serve as a probe for the rigidity of the solution space defined by a set of analytical constraints. In computational materials science and functional approximation, solution space rigidity—defined as the dimensionality of the function set satisfying all constraints—often dictates system uniqueness and predictability. A low-dimensional (rigid) solution space implies a unique or near-unique solution, while a high-dimensional (fat) space admits a continuum of solutions. We hypothesize that the minimal network width required to achieve zero violation (i.e., max absolute error ≤ 1e-3) on held-out constraints, denoted $N_c(w)$, as a function of constraint count $w$, can act as a diagnostic metric: if $N_c(w)$ remains flat or decreases with increasing $w$, the solution space is rigid; if it increases, the space is fat. This approach offers a data-driven, model-agnostic way to probe solution space structure without analytical derivation.

## Methods

We conducted a bootstrap capacity scan using a two-layer tanh-activated feedforward network optimized via `scipy.optimize.minimize` with the L-BFGS-B method. The network architecture had a single hidden layer with width $h \in \{2, 4, 8, 16, 32, 64\}$, and output layer of size 1. For each constraint family (rigid or fat) and each constraint count $w \in \{5, 10, 20\}$, we generated $w$ training points and $w$ held-out validation points using a random seed. The family function `family(kind, w, seed)` returned `{'X', 'y', 'Xv', 'yv'}` as reshaped (N, 1) arrays.

For each width $h$, we performed 3 independent optimizations with different random initializations (using `rng.standard_normal`) and selected the one with the lowest training MSE. Zero violation was declared if the maximum absolute error on held-out points was ≤ 1e-3. The minimal width $N_c(w)$ achieving this was recorded. We ensured the zero-violation condition was reachable by first verifying a high-capacity anchor point (e.g., $w=5, h=64$) achieved held-out error < 1e-3. All reported errors are finite; no inf/nan values were used.
