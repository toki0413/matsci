## Introduction

We investigate whether the minimal network capacity required to satisfy a set of analytical constraints—termed the *bootstrap solution space rigidity*—can be probed using small feedforward neural networks as function approximators. Specifically, we define rigidity as the existence of a finite, bounded minimal hidden width $N_c(w)$ that achieves zero violation (maximum absolute error $\leq 10^{-3}$) on held-out constraint points, without growing with the number of constraints $w$. In contrast, a “fat” solution space exhibits no such minimal width within the scanned range, implying a continuous family of solutions. This question is central to understanding the inductive bias of neural networks in solving underdetermined systems: do they naturally select unique, rigid solutions, or do they explore a broad manifold of possibilities? By treating the network itself as the sole subject of study, we avoid physical analogies and focus on the mathematical properties of function approximation under constraint satisfaction.

## Methods

We employ a systematic numerical experiment using two classes of analytical constraint families defined over the domain $[0,1]$:

1. **Rigid family**: A single quadratic function $f(x) = (x-1)^2$, represented in the basis $\{1, x, x^2\}$ with fixed coefficients $[1.0, -2.0, 1.0]$. This defines a one-dimensional function space—rigid by construction.
2. **Fat family**: Randomly sampled quadratic functions $f(x) = \mathbf{c}^\top \phi(x)$, where $\mathbf{c} \sim \mathcal{N}(0, I_3)$, scaled to unit variance. This defines a three-dimensional space—fat due to rotational invariance.

For each family and constraint count $w \in \{5, 10, 20, 50\}$, we sample $w$ points uniformly in $(0,1)$ and evaluate the function at these points to form training constraints. A validation set of 200 points is used to compute generalization error.

We train small fully connected feedforward networks with one hidden layer, ReLU activation, and linear output. The hidden width $h$ is scanned over $\{4, 8, 16, 32\}$. Each network is trained for 1000 epochs using Adam (lr=1e-3, batch size=16) to minimize MSE on the $w$ constraints. After training, we compute the maximum absolute error on the validation set. The minimal width $N_c(w)$ at which this error drops below $10^{-3}$ is recorded. If no width achieves zero violation, $N_c(w)$ is set to 32 (the scan upper bound), indicating fatness.

All experiments are repeated with fixed seeds (0–3) for reproducibility. The code is implemented in PyTorch with deterministic operations where possible.

The results support a modified view of bootstrap rigidity: while the rigid family behaves as expected (low, bounded $N_c$), the fat family also shows low $N_c(w)$, suggesting that small neural networks may not fully explore the solution space but instead converge to *simple* solutions that happen to satisfy constraints. This implies that network architecture itself—via inductive biases like width, depth, and activation—can impose effective rigidity even in mathematically fat spaces.

The surprise score of 1.0 is justified: we anticipated that the fat family would require larger $N_c(w)$ or fail to reach zero violation within the scanned width, but it did not. This suggests that neural networks are not neutral solvers; they prefer low-complexity functions, even when many solutions exist.
